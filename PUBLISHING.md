# Publishing

This directory is intended to be published as its own GitHub repository.

Suggested repository name:

```text
saldo-stellar-architecture
```

Suggested repository description:

```text
Architecture documentation for Saldo's Stellar USDC bill pay, SPEI settlement, and cash rail integration.
```

Initialize and publish:

```bash
cd saldo-stellar-architecture
git init
git add .
git commit -m "Add Stellar architecture documentation"
git branch -M main
git remote add origin git@github.com:<org>/saldo-stellar-architecture.git
git push -u origin main
```
